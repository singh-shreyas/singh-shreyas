#### **1. Automated Thermal Anomaly & Fire Hazard Prediction System** *(Smart India Hackathon)*
> **Stack:** Python • XGBoost • MongoDB (`2dsphere` spatial indexing) • NASA VIIRS/MODIS Satellite Telemetry  
> **Architecture:** Real-time satellite ingestion engine that isolates thermal hotspots across industrial grids using geospatial indexing and ML classification to trigger pre-symptomatic fire mitigation alerts.

#### **2. Nyaya-Sahayak — Multimodal Legal Tech Platform**
> **Stack:** React • Node.js • Python • Custom RAG Pipeline • Google Cloud Vision OCR  
> **Architecture:** Legal document parsing engine that automates legal notice generation over Indian statutory codes using custom vector search and document OCR workflows.

#### **3. CredDost — Agentic AI Personal Loan Sales Bot** *(EY Techathon)*
> **Stack:** Python • Agentic AI Frameworks • Express.js • MySQL  
> **Architecture:** Autonomous BFSI conversational platform engineered to qualify user credit profiles, process dynamic risk metrics, and deliver intelligent loan products in multi-turn dialogues.
